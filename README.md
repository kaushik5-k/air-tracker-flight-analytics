Air Tracker: Flight Analytics

Project Overview

Air Tracker is a flight analytics project built using Python, MySQL, and Streamlit. It helps users explore flight records, airline statistics, airport information, and flight delays.

Technologies Used

- Python
- MySQL
- Streamlit
- Pandas
- Plotly
- AeroDataBox API

Database Details

- Database: "air_tracker"
- Total Airports: 15
- Total Aircraft Records: 92
- Total Flight Records: 596

Dashboard Features

- Flight status visualization
- Top 10 airlines chart
- Flight search and filtering
- Airport details
- Flight delay analysis
- Busiest routes
- Flight records table

How to Run

1. Install the required Python libraries.
2. Configure MySQL credentials in ".streamlit/secrets.toml".
3. Run the dashboard:

python -m streamlit run app.py

Project Objective

To analyze flight data and visualize flight statuses, airport information, airline statistics, and delay patterns.

Security Note

Never upload API keys or database passwords to GitHub.
